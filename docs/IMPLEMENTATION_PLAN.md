# Implementation Plan

B0–B9 and M1–M6 now establish one restart-safe lifecycle for synthetic bootstrap evidence and
operator-adopted observational cohorts. Completion means the software contracts and offline
acceptance paths exist; it does not mean any source, method, Jev contract, or biological conclusion
has received scientific validation.

1. **M7 — Source adapters:** add reviewed provider-specific acquisition behind the existing adopted
   source contract; retain digest-pinned offline replay.
2. **M8 — Method validation:** pre-register evaluation datasets, thresholds, error analyses, and
   acceptance criteria for each real capability and Jev contract.
3. **M9 — Program expansion:** add programs only through explicit cancer scope and applicability
   review; never infer transfer from lung cancer.
4. **M10 — Operations:** add authenticated multi-operator Observatory views, audit export, retention,
   and credential management without exposing raw evidence to models.

No future milestone may introduce a mandatory modality sequence, dynamically load unreviewed code,
or turn literature, hypotheses, model confidence, or judgment into measurement.
