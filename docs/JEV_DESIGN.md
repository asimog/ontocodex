# Jev Design

Jev answers atomic, versioned questions when the answer space is known. OntoCodex proposes
and synthesizes; Jev selects, scores, gates, ranks, or abstains; Python computes and executes.

`RESEARCH_CONTROL` judgments may rank gaps, acquisitions, methods, or bounded next moves. They
are never biological evidence. `SCIENTIFIC_EVALUATION` includes Wide, Deep, and future
hypothesis critique and remains distinct from deterministic measurement.

Consequential contracts identify role, purpose, input projection, question version, primitive,
outputs, baseline, evaluation status, failure behavior, and model version. Their lifecycle is
`PROPOSED → EVALUATED → ACCEPTED | REJECTED → VERSIONED`.

Bootstrap evaluators are deterministic fakes behind these interfaces. Passing software tests
does not scientifically validate or promote a Jev contract.
