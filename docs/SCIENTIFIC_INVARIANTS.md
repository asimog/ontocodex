# Scientific Invariants

1. Missing is not zero.
2. Missing is not negative.
3. Partial is not complete.
4. A shard is not a population.
5. A hypothesis is not evidence.
6. Literature is not internal measurement.
7. Jev judgment is not measurement.
8. OntoCodex judgment is not measurement.
9. Model confidence is not evidence maturity.
10. Numerical results come from registered executable methods.
11. Method changes are explicit and versioned.
12. Threshold changes are explicit and versioned.
13. Cohort changes are explicit and versioned.
14. Cancer-scope changes are explicit and versioned.
15. Evidence-type interpretation changes are explicit and versioned.
16. Historical evidence is never rewritten.
17. Cross-cohort composition requires declared compatibility.
18. Cross-cancer applicability must be explicit.
19. Models never receive uncontrolled raw scientific data.
20. Acquisition is always bounded.
21. A normal ResearchRun has a 600-second hard maximum.
22. Temporary raw data is removed only after required durable output exists.
23. Research-control judgments never count as biological evidence.
24. Adopted sources require citation, license, release identity, scope, and content digest.
25. Missing source values are counted explicitly and never imputed by the prevalence method.
26. Replication uses a separately adopted cohort and a Candidate-phase capability.
27. Engineering verification can register packages but cannot dynamically import them.
